# 제품 아이콘

`app-icon.png`는 Chef al Mando의 제품 아이콘 원본입니다.
2026-09-09에 내장 이미지 생성 도구로 만들었으며, Godot 아이콘을 입력하거나 변형하지 않았습니다.
Godot의 프로젝트 아이콘 설정이 이 파일을 참조하며 각 플랫폼의 아이콘 크기는 내보내기 도구가 생성합니다.

## 제작 방향

짙은 청록색 배경에 구리색 팬, 구운 음식 세 조각, 토마토, 잎과 김을 배치했습니다.
첫 시안의 음식 질감을 단순한 형태와 명암으로 수정했습니다.
최종 요청에는 짧은 오른쪽 아래 손잡이, 크림색 김, 불투명한 정사각형 배경, 글자 없는 구성을 명시했습니다.

원본 크기는 1,254 × 1,254픽셀이며 알파 채널이 없습니다.

## Android 적응형 아이콘

`android-foreground.png`는 제품 원본을 바탕으로 이미지 생성 도구가 만든 투명 전경을 보정한 파일입니다.
운영자가 일반 이미지 처리를 승인한 뒤, Godot Image API로 알파가 0.1 미만인 잔여 픽셀을 제거하고 940 × 940픽셀로 축소했습니다.
이를 1,254 × 1,254픽셀 투명 캔버스의 중앙에 배치했습니다.
`android-background.png`는 432 × 432픽셀의 불투명 청록색 `#233738` 배경입니다.
두 파일은 `export_presets.cfg`의 Android 적응형 아이콘 설정에서 참조합니다.

최종 APK에서 추출한 전경의 모든 알파가 0보다 큰 픽셀은 중심 반경 29.222dp 안에 있습니다.
중앙 안전 반경 33dp를 충족하며, 원형과 둥근 사각형 마스크로 합성한 미리보기에서도 팬과 손잡이가 잘리지 않았습니다.
상세 근거는 [화면·아이콘 검증 기록](../../docs/notes/product-polish-verification.md)에 있습니다.
