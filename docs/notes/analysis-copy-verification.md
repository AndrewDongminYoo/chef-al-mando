# 마감 분석 문구 검증

작성일: 2026-09-15.
기준 명세는 [서비스 피드백](../specs/service-feedback.md)입니다.
구현 순서는 [서비스 피드백 구현 계획](../plans/service-feedback-implementation.md)의 작업 5와 작업 6에 있습니다.

## 문제와 범위

실제 한국어 휴대폰 마감 화면에서 제목 `다음 영업에서 바꿀 것`이 발주량 유지 제안과 맞지 않았습니다.
추천 본문에는 `경합` 같은 내부 용어, `남은 노동량 0는` 같은 동적 조사 오류, 목표값이 불명확한 `1 올리기`와 구체적인 선택을 알 수 없는 `운영 선택 하나`가 있었습니다.
추천 선정, 측정 수치, 정렬, 시뮬레이션과 저장 상태는 바꾸지 않고 표시 문구와 번역만 정리했습니다.
큰 글씨에서는 자동 줄바꿈이 `재료 부족 없음`, `중 하나만`, `181.0초`, `올려 보세요`와 `추가 손질`을 음절 사이에서 나눴습니다.
관찰 문장의 중복을 줄이고 행동 문장을 문장이나 절의 경계에서 명시적으로 나눴습니다.

## 문구 계약

- 제목은 유지와 변경을 모두 포괄하는 `다음 영업 추천`으로 바꿨습니다.
- 발주 유지 제안은 같은 발주·사용 수치를 반복하지 않고 유지할 재료와 비교할 선택인 프렙, 우선순위와 배치를 직접 표시합니다.
- 우선순위 제안은 `경합` 대신 `작업 대기`를 사용하고 다음 영업의 절대 목표값을 표시합니다.
- 프렙 상한 제안은 조사를 동적 수치에 직접 붙이지 않고 필요한 노동량과 남은 노동량을 각각 설명합니다.
- 영어 번역도 같은 정보와 행동 계약을 유지합니다.

## 최종 자동 검증

| 검사                      | 직접 읽은 속성                                                                                    | 결과                                             |
| ------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| Godot `--check-only`      | 프로젝트 스크립트와 리소스가 Godot 4.7.2에서 로드되는지 확인했습니다.                             | 종료 코드 0                                      |
| `scripts/check.sh m2`     | 한국어·영어 추천 문자열, 금지 표현과 마감 화면의 제목·상세 지표 순서를 확인했습니다.              | `PASS: m2 checks=494 failures=0`                 |
| `scripts/check.sh m3`     | 마감 화면을 포함한 캠페인 UI 계약과 기존 목록 스크롤 변경의 회귀를 확인했습니다.                  | `PASS: m3 checks=1109 failures=0`                |
| `scripts/check.sh m4`     | 정적 프로젝트 검사 뒤 시뮬레이션, 저장, 현지화와 화면 계약을 확인했습니다.                        | `PASS: m4 checks=1191 failures=0`                |
| 한국어 휴대폰 영업 피드백 | 큰 글씨 마감 화면의 다섯 의미 단위가 각각 한 줄 안에 유지되는지 실제 글자별 렌더 줄을 읽었습니다. | `Service feedback rendered checks=23 failures=0` |
| 영어 휴대폰 영업 피드백   | 큰 글씨 마감 화면에 같은 정보와 행동이 번역되어 배치되는지 렌더했습니다.                          | `Service feedback rendered checks=18 failures=0` |

`scripts/check.sh`는 ADB의 `tcp:5037` daemon에 연결하지 못했다는 경고를 출력했습니다.
자동 검사는 실패 0으로 끝났고 Android 실기기 상태는 읽지 않았습니다.

## 직접 렌더 확인

한국어 렌더 `build/check/service-feedback-hot-queue-ko-large-phone-wide-analysis.png`에서 관찰값이 한 줄로 정리되고 행동 문장이 문장이나 절의 경계에서 나뉘는 것을 확인했습니다.
`재료 부족 없음`, `중 하나만`, `181.0초`, `올려 보세요`와 `추가 손질`은 각각 한 줄 안에 유지됩니다.
영어 렌더 `build/check/service-feedback-hot-queue-en-large-phone-wide-analysis.png`에서 같은 정보가 제목과 첫 두 추천에 잘림 없이 표시되는 것을 확인했습니다.
세 번째 추천은 화면의 스크롤 영역 아래로 이어집니다.
자동 캡처는 분석 영역이 표시되는 것까지 확인하며, 손가락 스크롤 동작은 이번 문구 검증에서 별도로 확인하지 않았습니다.

## 남은 외부 검증

이번 변경은 실기기에 설치하지 않았습니다.
Android 실기기, VoiceOver와 TalkBack 검증은 이번 로컬 작업에 포함하지 않습니다.
