# M2 제작성 기록

작성일: 2026-09-08.
기준 계약은 [M2 구현 명세](../specs/m2-preparation.md)의 대표 아트와 데이터 제작성입니다.
이 기록은 에이전트의 제작 관찰이며 사람의 제작 시간이나 전체 콘텐츠 제작비를 추정하지 않습니다.

## 1. 출처와 제작 방식

직원 몸체 1개, 설비 4종, 메뉴 아이콘 3종을 `assets/m2/`에 SVG 원본으로 직접 작성했습니다.
외부 이미지, 생성 이미지 서비스, 외부 아트 패키지는 사용하지 않았습니다.
각 파일은 64×64 좌표계이며 같은 외곽선·색상·여백을 사용합니다.
직원은 같은 몸체에 색상과 번호를 붙여 구분하고, 이동 방향과 작업 표시는 `kitchen_board.gd`에서 그립니다.
아트와 표시가 시뮬레이션의 작업 완료를 결정하지 않습니다.

## 2. 자산별 시간과 검수

아래 시간은 도구 시계로 기록한 UTC 시작·종료의 차이입니다.
초안 작성은 2026-09-07 16:34:59–16:37:31 UTC, 개별 화면 검수는 같은 날 16:45:33–16:49:23 UTC에 수행했습니다.
이는 도구 호출과 중간 확인을 포함한 에이전트의 벽시계 시간이며 순수 드로잉 시간으로 해석하지 않습니다.
개별 검수 구간 사이의 다른 작업 시간은 합계에 넣지 않았습니다.

출고대 검수에서 작업 방향을 회전해도 아트 앞면이 아래쪽에 남는 문제를 발견했습니다.
SVG를 다시 그리지 않고 설비 아트를 실제 작업 위치 방향으로 회전하도록 표시 코드를 수정했습니다.
공통 표시 보정과 넓은 폰·태블릿 캡처 실행 구간은 16:47:51–16:48:28 UTC의 37초입니다.
보정 후 출고대 앞 손잡이가 오른쪽 작업 위치를 향하는 것을 다시 확인했습니다.
기계적 포맷·최적화와 전체 빌드 시간은 위의 자산별 초안 시간에 포함하지 않습니다.

검수 이미지는 작업 디렉터리의 `build/check/m2-ready.png`, `m2-prepped.png`, `m2-service.png`, `m2-phone-wide-layout.png`, `m2-tablet-service.png`입니다.
영업 화면의 작은 직원·설비와 준비 화면의 메뉴 아이콘을 직접 확인했습니다.
스크롤 영역의 경계에서 잘린 행은 스크롤로 읽을 수 있는지 별도 좌표 입력 검사로 확인했습니다.
이 증거는 데스크톱 렌더링이며 실기기의 가독성 수용 결과를 대신하지 않습니다.

## 3. 데이터만 추가한 메뉴

`tests/fixtures/m2_extra_menu.tres`에 `grain_salad`와 `prepped_grain_salad`를 추가했습니다.
명세의 원재료·노동량·손질·조리·매출·대기 한도를 데이터로 정의했고 기존 샐러드 아이콘을 재사용했습니다.
시뮬레이션과 제품 UI에는 이 메뉴 ID를 위한 분기를 추가하지 않았습니다.

콘텐츠 검사는 네 번째 메뉴의 로드, 프렙 생성, 실제 제공을 읽습니다.
메뉴 참조를 `missing_menu`로 바꾼 fixture는 `unknown scenario menu: missing_menu` 오류로 거부됩니다.
화면 검사는 동적으로 생긴 준비 버튼과 주문 이름을 읽고 실제 주문이 제공 상태가 되는지 확인합니다.
export 검사는 변환된 fixture를 포함한 팩을 별도 디렉터리에서 로드해 같은 동작을 확인합니다.
이 fixture는 기본 플레이 시나리오에 메뉴를 추가하는 캠페인 확장이 아닙니다.

## 4. 판단의 한계

대표 세트와 데이터 확장의 구현 경로는 확보했습니다.
한 에이전트의 짧은 제작 기록만으로 사람의 제작비, v1 전체 콘텐츠 수량, 플레이 시간을 확정하지 않습니다.
처음 접하는 사용자 5명의 관찰과 iPhone의 새 조작 확인은 [M2 검증 기록](m2-verification.md)에서 별도로 관리합니다.
M2 전체 통과와 M3 착수는 이 자동 검사 결과만으로 승인하지 않습니다.
