# 준비 단계의 메뉴별 기본 우선순위

2026-09-09에 승인한 보완 범위다.

- 준비 화면에서 판매 메뉴마다 기본 우선순위를 `0`부터 `2`까지 조절한다.
  초기값은 `1`이고 큰 값부터 배정한다.
- 새 주문은 도착한 틱의 배정부터 메뉴의 기본값을 사용한다.
  영업 중 주문별 우선순위 조절은 유지한다.
- 재도전과 영업 재개는 선택한 기본값을 유지한다.
  준비 초기화는 모두 `1`로 되돌린다.
- 저장에 기본값이 없으면 모두 `1`로 복원한다.
  기존 주문의 우선순위와 기록은 보존한다.
  알 수 없는 메뉴, 빠진 메뉴, 정수가 아닌 값, 범위 밖 값은 거부한다.
- 새 저장의 `schema_version`은 `3`이다.
  스키마 `1`과 `2`는 읽기만으로 변경하지 않고 다음 정상 저장에서 갱신한다.
  이전 실행 파일은 스키마 `3`을 미래 버전으로 보호한다.
  기존 준비의 결과는 같으므로 `content_version`과 `sim_version`은 유지한다.
- 주문 일정, 마감, 목표, 재료, 작업 시간은 변경하지 않는다.

검증은 `bash scripts/check.sh m2`, `bash scripts/check.sh m3`, `bash scripts/check.sh m4`를 사용한다.
메뉴 설정의 실제 버튼 입력, 기본값 도착 적용, 개별 변경, 초기화, 기존 저장 호환, 재개 이후 주문, 잘못된 저장 거부를 확인한다.
`hot_queue`는 그릴 프렙 4개와 가까운 배치, 그릴 기본 우선순위 `2`로 영업 중 추가 명령 없이 목표를 달성해야 한다.
같은 준비에서 `1x`와 `4x`의 최종 상태 해시를 비교한다.
