# UI·UX 정보 위계 개선

작성일: 2026-09-14.
상태: 로컬 구현 및 검증 완료.

## 1. 목적

영업 화면에서 시간, 직원 상태와 마감 행동을 빠르게 읽을 수 있게 합니다.
주문 취소 버튼에는 실제 눌림 상태를 추가합니다.
기존 게임 규칙, 화면 구조, 저장 형식과 콘텐츠는 유지합니다.

## 2. 범위

이번 변경은 다음 네 항목만 포함합니다.

1. 상단의 남은 시간과 경과 시간에 각각 이름을 표시합니다.
2. 직원별 현재 행동과 대기 원인의 글자 크기를 높입니다.
3. 마감 분석에서 다음 행동을 관찰 근거보다 약하게 표시하지 않습니다.
4. 주문 취소 버튼의 눌림 상태를 기본 상태와 시각적으로 구분합니다.

새 UI 프레임워크, 새 의존성, 새 설정, 화면 전환과 시뮬레이션 규칙은 추가하지 않습니다.
기존 M0 생명주기 카운터를 제거하지 않습니다.

## 3. 시간 표기

영업 헤더는 남은 시간과 경과 시간을 다음 형식으로 표시합니다.

- 한국어: `남은 시간 299.0초 · 경과 001.0초`
- 영어: `Time remaining 299.0 s · Elapsed 001.0 s`

남은 시간은 기존 `Remaining` 레이블에 표시합니다.
경과 시간은 기존 `Counter` 레이블에 표시합니다.
게임 tick, 일시정지, 배경 전환과 복귀 동작은 변경하지 않습니다.

## 4. 직원 상태

직원 상태 문구의 기본 글자 크기는 18입니다.
큰 글씨 설정에서는 기존 1.2배 규칙을 적용하여 22로 표시합니다.
직원 상태 문구는 최대 4줄을 사용합니다.
메뉴, 현재 공정과 대기 원인을 유지합니다.
4인 영어 화면의 재료 이동 목적은 `fetching prep`과 `fetching raw`로 간결하게 표시합니다.

## 5. 마감 행동

`다음 영업 추천` 아래의 행동 문장은 관찰 문장과 같은 글자 크기를 사용합니다.
행동 문장은 기존 구리색 강조색을 사용합니다.
관찰, 해석, 행동의 내용과 추천 순서는 변경하지 않습니다.
상세 지표는 행동 제안 뒤에 유지합니다.

## 6. 주문 취소 눌림 상태

`DangerButton`은 기존 위험색 기본 상태를 유지합니다.
눌림 상태는 더 어두운 채움과 2픽셀 구리색 테두리를 사용합니다.
hover와 pressed 상태의 렌더 픽셀은 서로 달라야 합니다.
버튼 크기, 위치, 문구와 취소 명령은 변경하지 않습니다.

## 7. 수용 기준

| ID     | 요구사항                                                                        | 검증                                                      |

| UIH-01 | 한국어와 영어에서 두 시간 값의 의미가 드러납니다.                               | M0·M4 UI 테스트가 준비·일시정지·마감 표기를 확인합니다.   |
| UIH-02 | 직원 상태는 기본 18, 큰 글씨 22로 표시되고 4인 영어 화면에서도 잘리지 않습니다. | M2·M4 UI 테스트와 실제 휴대폰·태블릿 렌더를 확인합니다.   |
| UIH-03 | 행동 문장은 관찰 문장과 같은 크기이며 구리색으로 강조됩니다.                    | M2 UI 테스트와 마감 분석 렌더를 확인합니다.               |
| UIH-04 | 취소 hover와 pressed 픽셀이 다릅니다.                                           | 제품 마감 캡처가 실제 버튼 입력과 렌더 픽셀을 확인합니다. |

## 8. 검증 한계

렌더 캡처는 캡처한 화면의 픽셀과 fixture가 수행한 입력만 증명합니다.
실제 Android 기기, 실제 태블릿, VoiceOver와 TalkBack 검증은 이번 범위에 포함하지 않습니다.
