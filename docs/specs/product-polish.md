# 제품 화면과 아이콘 마감

2026-09-09에 승인한 제품 화면·아이콘 마감의 범위입니다.
배포 후보 준비보다 화면의 완성도를 먼저 높입니다.

## 범위

- 짙은 청록색 바탕, 크림색 글자, 구리색 강조를 공통 Godot Theme으로 적용합니다.
- 영업 목록, 준비, 영업 중, 마감 분석에 같은 버튼과 패널 표현을 사용합니다.
- 선택한 탭·주문·배속과 실행 버튼을 구분합니다.
- 기존 평면 시점과 설비 그림을 유지하며 바닥·벽·작업 위치의 구분을 다듬습니다.
- 팬과 음식이 보이는 제품 아이콘을 프로젝트 원본으로 등록합니다.

## 성공 기준

1. 한글·영문과 기본·큰 글씨를 휴대폰·태블릿 크기로 렌더링합니다.
   검증: `tests/capture_product_polish.gd`가 실제 장면을 실행하고 화면 이미지를 저장하며, 주요 버튼의 안전 영역과 글자 표시 범위를 검사합니다.
   저장한 화면을 직접 읽어 시각적 구분과 잘림을 확인합니다.
2. 시뮬레이션 결과와 저장 동작을 유지합니다.
   검증: `scripts/check.sh m1`, `m2`, `m3`, `m4`, `m5`를 실행합니다.
3. 불투명한 정사각형 아이콘을 사용하고 기존 Godot 아이콘 파생 안내를 제거합니다.
   검증: 원본 이미지 메타데이터, 내보낸 앱의 아이콘, 라이선스 본문 검사를 확인합니다.

## 경계

게임 규칙, 콘텐츠 수, 저장 버전, 입력 명령, 앱 ID를 변경하지 않습니다.
새 의존성이나 UI 프레임워크를 추가하지 않습니다.
이 작업은 출시 또는 외부 배포의 승인을 뜻하지 않습니다.
